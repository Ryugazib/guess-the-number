# Guess the Number

My second Python project.

A simple number guessing game made with Python.

## How to Play

1. Enter your name.
2. The computer generates a random number from 1 to 10.
3. Try to guess the number.
4. If your guess is wrong, you can guess again.
5. The game ends when you guess the correct number.
